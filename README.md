# Ficha técnica

App web (PWA) para confeccionar fichas técnicas de cocina desde el móvil y guardarlas en PDF con el formato de la plantilla.

**Abrir la app:** https://ezekcm.github.io/ficha-tecnica/

## Instalar en el móvil
- **Android (Chrome):** abre el enlace → menú ⋮ → *Añadir a pantalla de inicio* / *Instalar app*.
- **iPhone (Safari):** abre el enlace → botón Compartir → *Añadir a pantalla de inicio*.

## Cómo funciona
- Rellena nombre, tipo, ingredientes (cantidad y unidad), foto, alérgenos y elaboración. Se puede dictar con el micrófono del teclado.
- **Crear PDF** genera la ficha rellena; se puede descargar o compartir (WhatsApp, correo, Archivos…).
- Las fichas se guardan solo en el propio móvil. Para pasarlas a otro dispositivo: *Mis fichas → Exportar copia / Importar copia*.
- Funciona sin conexión una vez abierta la primera vez.

Tipografía de los PDF: TeX Gyre Bonum (GUST Font License). Generación de PDF: jsPDF (MIT).
